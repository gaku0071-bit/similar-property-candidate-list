# 類似物件候補リスト

営業支援の問い合わせ物件を基準に、リアプロから類似物件候補を作成するChrome拡張機能です。

## 初回導入

1. [最新版ZIPをダウンロード](https://github.com/gaku0071-bit/similar-property-candidate-list/releases/latest/download/similar-property-candidate-list.zip)します。
2. ZIPを任意の固定フォルダへ展開します。
3. Chromeで`chrome://extensions`を開き、デベロッパーモードを有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. `manifest.json`が入っている展開先フォルダを選択します。

## 更新方法

1. 営業支援画面の「最新版ZIPをダウンロード」を押します。
2. ZIPを展開し、現在Chromeで読み込んでいる拡張機能フォルダへ中身を上書きします。
3. Chromeで`chrome://extensions`を開きます。
4. 「営業支援 類似物件抽出」の「再読み込み」を押します。
5. 営業支援画面を再読み込みします。

## 現在のバージョン

`0.13.12`

## v0.13.12の変更点

- 問合せ物件一覧に「メールにコピー」の選択チェックを追加
- 選択した問合せ物件の「物件名・部屋番号・顧客向けURL」を一括コピー
- 顧客向けURL未取得の物件はコピー対象から除外し、取得状態を表示

## v0.13.11の変更点

- 営業支援の現行URL `/home/{顧客ID}/activities` に対応
- 顧客の「活動・メッセージ」画面で「候補リストを作成」ボタンを表示
- 旧URLにも対応し、営業支援の顧客一覧ページではボタンを引き続き非表示

## v0.13.10の変更点

- 営業支援の案件一覧では候補リストボタンを表示せず、案件詳細だけで表示
- リアプロの検索結果一覧にあった「この検索結果を候補化」を削除
- 複数問合せはリアプロ詳細リンクを先に表示し、顧客向けURLは続けて取得
- 問合せ号室がない場合は同じ建物の募集中の別部屋を案内。申込・審査・商談中は除外
- リアプロの「スタジオタイプ」を問合せの「1R」と照合

## v0.13.5の変更点

- 別のお客様で「候補リストを作成」を押した時点で、前のお客様の条件・候補・進捗を消去
- 同じお客様の複数問合せ物件は維持
- 問合せ物件を先に表示し、過去履歴を後から読み込むことで初期表示を高速化
- リアプロの沿線名へ「交通」見出しが混ざり、沿線を選択できなくなる問題を修正

## 注意

- リアプロなどのID・パスワードは、このリポジトリや配布ZIPに保存していません。
- Chromeへ開発中の拡張機能として読み込むため、ZIPの展開・上書き・拡張機能の再読み込みは手動です。
- 旧バージョンへ戻す場合は、GitHub Releasesから該当バージョンをダウンロードしてください。
